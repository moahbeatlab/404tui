Everywhere: `1`–`7` change tab, `Ctrl-R` records the unit's audio, `Ctrl-F` full screen, `Ctrl-T` next
theme, `r` refresh, `?` keys, `:` command palette, `q` quit. `sp404 check` checks the installation.
